# files

Plain functions for paths, glob patterns and file walks on Node.js. They use only `node:` modules.

| Package | Description |
| --- | --- |
| [`@mark1russell7/files`](packages/files) | The home folder, a path inside a folder, find-up, glob patterns and file walks with excludes |

The site has a glob tester: <https://mark1russell7.github.io/files/>.

## Work on the repository

```sh
pnpm install
pnpm test
pnpm typecheck
```

`docs/ROADMAP.md` has the plan. `RELEASING.md` tells how a release works.
